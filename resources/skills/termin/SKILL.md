---
name: termin
description: Einen bestätigten Gesprächszeitraum einer Stelle als Kalenderdatei vorbereiten.
---

Prüfe Einladung, Rolle, Gesprächsrunde, Datum, Beginn, Ende und Zeitzone. Bei mehreren Alternativen den Terminstand offenlassen. Keinen Termin zusagen oder Einladungen verschicken.

Lokal `termin ID --runde ... --start ... --ende ... --quelle ...` mit den tatsächlichen UTC-Versätzen verwenden. Verschiebungen behalten dieselbe Runde. Für einen ausdrücklich gewünschten nativen Kalendereintrag auf macOS `--mac --kalender NAME` verwenden. `--vormerkung` kennzeichnet eine persönliche Option. Nach Import oder Speicherung Zeit und Eintrag prüfen. Ohne Kalenderzugriff die ICS-Datei oder die Daten zur Übernahme liefern. Siehe docs/TERMINE.md.
